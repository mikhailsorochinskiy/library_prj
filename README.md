# Online Library API 📚

RESTful API сервис для управления онлайн-библиотекой. Проект разработан в качестве серверной части дипломной работы.

## 🚀 Основной функционал
- **Аутентификация и авторизация:** JWT-токены, подтверждение регистрации по email, восстановление пароля.
- **Ролевая модель:** Разделение прав доступа (Читатели, Модераторы, Администраторы).
- **Каталог книг:** Просмотр списка авторов и книг, фильтрация по жанрам и читательским диспозициям.
- **Работа с файлами:** Защищенная загрузка и скачивание файлов текстов книг (PDF, FB2, EPUB).
- **Социальные функции:** Оставление комментариев, выставление оценок книгам (от 1 до 10).
- **Персонализация:** Добавление книг в «Избранное», подписка на любимых авторов.
- **Геймификация:** Автоматическое начисление баллов активности за оставленные комментарии, оценки и подписки.

## 🛠 Технологический стек
- **Язык:** Python 3.11
- **Фреймворк:** Django 5.2 + Django REST Framework
- **База данных:** PostgreSQL
- **Сервер приложений:** Gunicorn
- **Контейнеризация:** Docker, Docker Compose
- **Документация:** Swagger (drf-yasg) / ReDoc

## ⚙️ Локальный запуск (с помощью Docker)

Для быстрого развертывания проекта используется Docker. Вам не нужно устанавливать Python или PostgreSQL на свой компьютер.

### 1. Клонирование репозитория
```bash
git clone <ссылка_на_твой_репозиторий>
cd library_prj
```
### 2. Настройка переменных окружения
В корне проекта создайте файл .env на основе файла шаблона:
```bash
cp .env.sample .env
```
Заполните файл .env необходимыми данными (настройки БД, почты, секретные ключи).
### 3. Сборка и запуск контейнеров
Выполните команду для запуска базы данных и бэкенда:
```bash
docker-compose up -d --build
```
При первом запуске Docker автоматически выполнит:

Применение миграций базы данных.

Сборку статических файлов.

Создание базовых групп пользователей (Readers, Moderators).

Создание суперпользователя (email: admin@mail.ru, password: admin).
### 4. Доступ к проекту
После успешного запуска проект будет доступен по следующим адресам:
API: http://127.0.0.1:8000/

Панель администратора: http://127.0.0.1:8000/admin/

Документация Swagger: http://127.0.0.1:8000/swagger/

Документация ReDoc: http://127.0.0.1:8000/redoc/

### 5. Остановка проекта
Для остановки работы контейнеров выполните команду:
```bash
docker-compose down
```
Примечание: Данные базы данных и загруженные файлы (книги/картинки) сохраняются в Docker Volumes и не будут удалены при остановке контейнеров.
### 6. Настройка отправки писем (SMTP)
Для работы функционала подтверждения регистрации и сброса пароля убедитесь, что в файле .env указаны корректные настройки SMTP-сервера:
EMAIL_HOST=smtp.yandex.ru
EMAIL_PORT=465
EMAIL_USE_SSL=True
EMAIL_HOST_USER=your_email@yandex.ru
EMAIL_HOST_PASSWORD=your_app_password
DEFAULT_FROM_EMAIL=your_email@yandex.ru
Если настройки не указаны, письма будут выводиться в консоль (режим отладки).
